# 2. Historias de Usuario

Necesidades desde la perspectiva de quien utilizará el sistema, incluyendo validaciones de stock y casos excepcionales.

| ID | Historia de usuario |
| :--- | :--- |
| **HU01** | Como cliente, quiero ver el calendario de disponibilidad de las salas, para elegir un horario que no esté ocupado. |
| **HU02** | Como cliente, quiero buscar y agregar equipos musicales extra a mi reserva **que estén disponibles en mi horario elegido**, para tener todo listo al momento de ensayar sin generar conflictos de stock con otras salas. |
| **HU03** | Como cliente, quiero completar el pago de mi reserva online, para asegurar mi espacio sin tener que ir al local previamente. |
| **HU04** | Como cliente, quiero poder consultar las políticas de cancelación y anular mi reserva con anticipación, para liberar el espacio si se me presenta un imprevisto. |
| **HU05** | Como administrador, quiero registrar y actualizar la información de las salas y equipos (precios, fotos, **cantidad en stock** y estado), para mantener el catálogo al día. |
| **HU06** | Como administrador, quiero visualizar un panel con todas las reservas del día/semana, para preparar los equipos antes de que lleguen las bandas. |
| **HU07** | Como administrador, quiero poder bloquear manualmente ciertas fechas u horarios (por mantenimiento de sala o feriados cerrados), para evitar que los clientes reserven cuando el local no puede operar. |
| **HU08** | Como administrador, quiero poder cancelar reservas manualmente si ocurre un problema de fuerza mayor (ej. corte de luz) o si el cliente no cumple las políticas, para mantener el control total del local. |
