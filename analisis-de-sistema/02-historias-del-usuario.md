# 2. Historias de Usuario

Necesidades desde la perspectiva de quien utilizará el sistema.

| ID | Historia de usuario |
| :--- | :--- |
| **HU01** | Como cliente, quiero ver el calendario de disponibilidad de las salas, para elegir un horario que no esté ocupado. |
| **HU02** | Como cliente, quiero buscar y agregar equipos musicales extra a mi reserva, para tener todo listo al momento de ensayar. |
| **HU03** | Como cliente, quiero completar el pago de mi reserva online, para asegurar mi espacio sin tener que ir al local previamente. |
| **HU04** | Como administrador, quiero registrar y actualizar la información de las salas y equipos (precios, fotos, estado), para mantener el catálogo al día. |
| **HU05** | Como administrador, quiero visualizar un panel con todas las reservas del día/semana, para preparar los equipos antes de que lleguen las bandas. |
