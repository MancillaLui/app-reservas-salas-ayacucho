# 5. Restricciones

Condiciones, reglas o limitaciones que deben respetarse durante el desarrollo del sistema.

| ID | Restricción | Descripción |
| :--- | :--- | :--- |
| **RC01** | **Presupuesto y Equipo** | El sistema debe ser desarrollado, desplegado y mantenido por un solo desarrollador, minimizando costos de infraestructura. |
| **RC02** | **Aplicación Web** | La solución debe ser una aplicación web responsiva, sin requerir la instalación de aplicaciones nativas. |
| **RC03** | **Backend-as-a-Service** | Se debe utilizar un servicio backend gestionado (como Supabase o Firebase) para manejar la base de datos y autenticación. |
| **RC04** | **API REST** | La comunicación entre el frontend y los servicios del sistema debe realizarse mediante una API REST. |
