# App Web de Reservas de Salas de Ensayo y Equipos - Ayacucho

## Autor
* MANCILLA APCHO, Luis Alejandro

## Descripción
Aplicación web diseñada para automatizar y gestionar las reservas de salas de ensayo musical y el alquiler de instrumentos/equipos en la ciudad de Ayacucho. El sistema permite a los músicos locales verificar disponibilidad en tiempo real, evitar cruces de horarios (overbooking) y gestionar sus reservas de forma digital.

## Caso de estudio
Gestión y optimización de reservas para locales de ensayo musical y alquiler de equipos de sonido.
