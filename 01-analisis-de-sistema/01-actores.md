# 1. Actores del Sistema

¿Quién o qué interactúa con el sistema desde fuera para realizar una acción o intercambiar información?

| Actor | ¿Qué necesita realizar? |
| :--- | :--- |
| **Cliente (Músico/Banda)** | Buscar salas y equipos, verificar disponibilidad, agregar reservas al carrito, registrar datos de contacto y realizar pagos. |
| **Administrador (Propietario)** | Administrar el catálogo de salas y equipos (CRUD), gestionar reservas (aprobar/cancelar), verificar reportes de ingresos y ocupación. |
| **Pasarela de pago** | Procesar y validar pagos digitales (Tarjetas, Yape, Plin). |
| **Proveedor de Identidad** | Gestionar el inicio de sesión seguro (Ej. Google Auth). |
