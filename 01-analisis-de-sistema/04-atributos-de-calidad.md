# 4. Atributos de Calidad

Características que indican cómo debe funcionar el sistema, más allá de sus funcionalidades.

| ID | Atributo de calidad | Escenario de calidad |
| :--- | :--- | :--- |
| **AC01** | **Rendimiento** | El calendario y el catálogo deben cargar en menos de 3 segundos, incluso en conexiones de redes móviles (3G/4G). |
| **AC02** | **Disponibilidad** | El sistema debe estar disponible 24/7 para permitir reservas fuera de horario comercial. |
| **AC03** | **Seguridad** | Los datos personales y los registros de pago de los clientes deben estar protegidos frente a accesos no autorizados. |
| **AC04** | **Usabilidad** | La interfaz debe tener un diseño "Mobile-First", asegurando que los músicos puedan reservar fácilmente desde sus teléfonos móviles. |
